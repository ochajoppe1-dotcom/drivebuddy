# 🚛 DriveBuddy（ドライブバディ）

プロドライバーの毎日に、頼れる相棒を。

大型・中型ドライバーのための実用PWAアプリ。

## 機能

| 機能 | 説明 |
|---|---|
| 🅿️ **駐車場マップ** | 大型対応の駐車場・休憩スポットを検索 |
| ⛽ **燃料価格比較** | 周辺のガソリン・軽油価格をリアルタイム比較 |
| 🧾 **経費レシート記録** | 写真撮影でAI自動仕訳・確定申告対応 |
| ⏱️ **拘束時間チェッカー** | 2024年問題対応・法令違反を事前警告 |

## 技術構成

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **PWA** (manifest.json)
- **Vercel** デプロイ
- **Claude API** (AI機能・予定)
- **Supabase** (DB・予定)

## ローカル開発

```bash
npm install
npm run dev
```

http://localhost:3000 でアクセス。
